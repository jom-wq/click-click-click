GREETINGS WEBSITE - READY TO RUN

1. Extract this ZIP.
2. Open the folder.
3. Double-click index.html.
4. Drag the pink ribbon downward.
5. When the envelope opens, the surprise screen appears.
6. Click "Open Your Letter" to see the letter.

Files:
- index.html
- style.css
- script.js

To edit the letter, open index.html and change the text inside .letter-content.
